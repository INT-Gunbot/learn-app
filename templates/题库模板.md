## SQL 高频考点

### 窗口函数和 GROUP BY 的区别
窗口函数在不减少行数的前提下做聚合计算，GROUP BY 会把多行聚合成一行。窗口函数用 OVER() 定义窗口范围。
> ROW_NUMBER() OVER (PARTITION BY user_id ORDER BY created_at DESC)

### LEFT JOIN 保留哪些行
保留左表的全部行，右表没有匹配时补 NULL。统计「有行为/无行为」用户时常用 LEFT JOIN + IS NULL 做差集。
> SELECT * FROM a LEFT JOIN b ON a.id = b.a_id WHERE b.a_id IS NULL

### COUNT(*) 与 COUNT(col) 的差异
COUNT(*) 统计行数（含 NULL 行），COUNT(col) 只统计该列非 NULL 的行数，COUNT(DISTINCT col) 统计去重后的非 NULL 值。

## 指标体系

### 北极星指标
唯一能同时代表用户价值与公司收益的指标，用来对齐全团队，随产品阶段演进。
> 搜索产品可能是「有效搜索次数」，不是注册用户数

### 同期群分析 Cohort
按用户进入时间分组追踪随时间表现，剥离用户结构变化带来的假象，判断改版是否真的有效。
> 整体留存上升，可能是新用户质量变好；分同期群看老用户反而下降
